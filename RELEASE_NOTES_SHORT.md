# Divani Mods v1.3.3 - Workhorse and Betrayer

> [!NOTE]
> Not guaranteed to work on Town Of Us versions newer than 1.6.2.

## Added

**Role: Workhorse** (Crewmate Power)
A Crewmate that gets extra tasks after finishing their original list. Completing the total list can grant an instant Crewmate win, but killers are alerted as you get close.

**Modifier: Betrayer** (Alliance, Impostor only)
An Impostor that turns on their team. Wins like a Neutral Killer: be the last killer standing. Impostors learn the Betrayer's identity when few players remain, or if an Impostor dies while 2+ Impostor-aligned players are alive. Betrayers never win with the Impostors.

## Bugfixes
- **Armored**: failed murder attempt now always sets the short cooldown.
- **Cupid**: provisional lovers no longer counted as established (caused role change on Cupid)
- **Duelist**: fixed some skins showing when duellers return to the ship.
- **Retributionist**: Cursed killers can no longer vent.

## Changes
- **Duelist**: duels can tie (0.15s window); dropped post-first-click kill protection.
- **Demolitionist**: local setting to disable alternating flash/arrow colors; clearer "Consoles" description.
- **Mage**: Egotist and Crewpostor Mage supported. Energize buffs Impostors and Crewpostor/Egotist crew, nerfs Crew; Crewpostor Mage nerfs Neutral Killing/Evil, Egotist buffs them.
- **Mole**: vent access defaults to all players; host can grant extra vents via tasks; added vent cooldown and max stay time.
- **Thief / Sprout**: random pool only includes host-enabled modifiers.
- **Retributionist**: option to continue the game (default off).
- **Portalmaker**: smarter portal placement (away from tasks/consoles/doors/walls); Use button overrules portal button; clicking a portal uses it; steadier pet-button behaviour; added use-portal cooldown.
- Ordered modifiers in settings better.
